# Digital Clock

A simple real-time digital clock developed using Python and Tkinter.

## Project Overview

The project displays the current time in a graphical user interface and updates automatically in real time. It was created to practise Python programming and develop experience with graphical user interfaces.

## Features

* Displays the current time
* Real-time automatic updates
* Graphical user interface
* 12-hour/24-hour time formatting
* Simple and user-friendly design

## Technologies Used

* **Python** – Main programming language
* **Tkinter** – Graphical user interface
* **Datetime** – Used to retrieve and format the current time

## What I Learned

This project helped me develop my understanding of Python programming and GUI development. I gained experience working with Tkinter, functions, time formatting and continuously updating information within a graphical interface.
